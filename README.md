# 🚀 Mini_Insta - Your Personal Social Media Hu
Welcome to **Mini_Insta**, a sleek and powerful mini social media platform built with Node.js, Express, and EJS. Experience the essence of Instagram with user profiles, image uploads, search functionality, and more – all in a lightweight, easy-to-deploy application!

## ✨ Features

- **🔐 User Authentication**: Simple login system with automatic user creation.
- **👤 Profile Management**: View and update user profiles with bios, followers, and following counts.
- **📸 Image Uploads**: Upload and display profile pictures seamlessly.
- **🔍 Search Users**: Find other users by username with real-time search results.
- **🎨 Dynamic UI**: Responsive design with EJS templating for a smooth user experience.
- **⚡ Fast & Lightweight**: Built for performance with minimal dependencies.
- **🖼️ Interactive Photos**: Hover effects and smooth transitions on profile images for an engaging interface.

## 🛠️ Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/mini_insta.git
   cd mini_insta
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the server**:
   ```bash
   npm start
   ```

4. **Open your browser** and navigate to `http://localhost:8080`.

## 📖 Usage

- **Login**: Enter a username on the homepage to log in or create a new account.
- **Profile**: View your profile, update your bio, and upload a new profile picture.
- **Search**: Use the search bar to find other users and explore their profiles.
- **Upload**: Change your profile picture by uploading a new image.
